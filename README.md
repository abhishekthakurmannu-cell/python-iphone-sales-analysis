## 📌 Project Overview

This project focuses on analyzing Apple iPhone product and sales-related data using Python. The goal is to explore the dataset, identify meaningful patterns, understand product-related trends, and extract useful insights through Exploratory Data Analysis (EDA).

Using Python and data analysis techniques, this project demonstrates how raw product data can be explored and transformed into meaningful information.

## 🎯 Project Objectives

- Explore and understand the Apple products dataset.
- Perform data cleaning and preprocessing.
- Analyze product-related information.
- Identify patterns and trends in the dataset.
- Perform Exploratory Data Analysis (EDA).
- Generate meaningful insights using Python.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/abhishekthakurmannu-cell/python-iphone-sales-analysis.git
```

**2. Navigate to the project directory**

```bash
cd python-iphone-sales-analysis
```

**3. Install the required libraries**

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**4. Launch Jupyter Notebook**

```bash
jupyter notebook
```

**5. Open the notebook**

Open `analysis.ipynb` and run the cells to explore the analysis.
